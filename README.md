# Nithin Bairoju - Portfolio

Modern, minimal portfolio website showcasing backend engineering work and projects.

## 🎨 Design
- **Color Scheme**: Black/Lime Green/Yellow
- **Style**: Modern Minimal with storytelling focus
- **Features**: Scroll progress, smooth animations, responsive design

## 🚀 Quick Start

```bash
# Install dependencies (if not done)
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

```
src/
├── sections/          # Main page sections
│   ├── Hero.jsx      # Landing section
│   ├── Story.jsx     # Journey timeline
│   ├── Experience.jsx # Work case study
│   ├── Skills.jsx    # Tech arsenal
│   ├── Projects.jsx  # Project showcase
│   ├── Philosophy.jsx # Engineering approach
│   └── Contact.jsx   # Contact info
├── assets/
│   └── illustrations/ # ADD YOUR IMAGES HERE
├── App.jsx           # Main app component
├── index.css         # Global styles
└── main.jsx          # Entry point
```

## 🖼️ Adding Illustrations

Place your generated images in `src/assets/illustrations/`:

1. `hero-builder.png`
2. `backend-arch.png`
3. `skills-tools.png`
4. `project-dashboard.png`
5. `engineering-mind.png`
6. `contact-network.png`

## 🛠️ Built With

- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide React (icons)

## 📝 Customization

Update content in each section file:
- Personal info → `Hero.jsx`, `Contact.jsx`
- Experience → `Story.jsx`, `Experience.jsx`
- Skills → `Skills.jsx`
- Projects → `Projects.jsx`
- Philosophy → `Philosophy.jsx`

## 🌐 Deploy

```bash
# Build
npm run build

# Deploy to Vercel
vercel deploy

# Or Netlify
netlify deploy
```
