# Nithin Bairoju | Digital Marketer & Growth Strategist Portfolio

Modern, high-performance portfolio website built with **pure HTML, CSS, and JavaScript**.

## 🎨 Design & Architecture
- **Tech Stack**: Pure HTML5, Vanilla CSS3, Vanilla JS (No npm, no Vite, no build step required).
- **Color Scheme**: Dark aesthetic (`#030303`) with neon lime green accents (`#84cc16`).
- **Features**: Smooth animated text marquee, scroll progress bar, mouse parallax hero effect, responsive drawer navigation, and scroll-reveal animations.

## 🚀 How to Run & Edit

Simply double click `index.html` or open `index.html` in any web browser!

- **Main Page**: `index.html`
- **Styles**: `styles.css`
- **Logic & Animations**: `script.js`
- **Image Assets**: `assets/`

## 📁 File Structure
